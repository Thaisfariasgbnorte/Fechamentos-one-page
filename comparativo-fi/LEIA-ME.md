# Comparativo F&I — histórico de fechamentos

Código da página publicada em https://claude.ai/artifact/VdxkL4QVbPLk9HwsPmrkZY.

- **Atualizar sem o Claude**: abra o link (logada no claude.ai, como editora), "Baixar planilha base",
  atualize no Excel, "Enviar planilha atualizada", confira a prévia, dê um nome e clique em
  "Salvar como novo fechamento".
- **Histórico**: cada envio é guardado como um fechamento separado (banco de dados da página,
  coleção `fechamentos`). Os anteriores não mudam; escolha qual ver no filtro "Fechamento".
  Só editores salvam ou excluem; quem só visualiza vê todos os fechamentos.
- **PDF**: botão "Gerar PDF" (A4 paisagem), com o nome do fechamento no cabeçalho.
- Os dados embutidos no arquivo aparecem como "Versão original da página".
